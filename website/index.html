Sebelum mulai.

Beberapa hal yang mungkin ingin kamu tahu.

Saku tersedia untuk sistem operasi apa?

Saat ini Saku dibuat untuk Windows x64. Versi untuk sistem operasi lain belum tersedia.

Apakah file saya diunggah ke internet?

Operasi Batch Rename dan dokumen yang kamu buka berlangsung di komputer sendiri. Gambar Markdown dari tautan web tetap memerlukan internet.

Bagaimana cara mendapat pembaruan?

Unduh versi terbaru dari halaman rilis. Catatan di halaman ini dan rilis GitHub merujuk pada rilis stabil yang sama.

Apakah Saku gratis dan open source?

Ya. Kode Saku tersedia di GitHub dengan lisensi MIT.
